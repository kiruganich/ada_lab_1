# Словарь на B-дереве

Материалы для подготовки к лабораторной работе по алгоритмам и дискретному анализу: вариант «E. 4 B-дерево» и связанное задание «G. Отчёт + качество программ».

Сначала прочитать [разбор B-дерева](docs/BTREE_GUIDE.md), затем [проектирование словаря](docs/DICTIONARY_DESIGN.md) и [проверки и подготовку отчёта](docs/TESTING_AND_REPORT.md).

| Материал | Содержание |
| --- | --- |
| [B-дерево](docs/BTREE_GUIDE.md) | Инварианты, высота, поиск, вставка, все случаи удаления, примеры и вопросы к защите |
| [Устройство словаря](docs/DICTIONARY_DESIGN.md) | Требования, интерфейс библиотеки, строки и числа, владение памятью, двоичный формат, Save и Load, ошибки |
| [Проверки и отчёт](docs/TESTING_AND_REPORT.md) | Граничные случаи, сравнение с эталоном, проверка инвариантов, gprof, Valgrind, измерения и дневник |

В репозитории пока находятся учебные материалы. Реализация словаря и результаты её проверки появятся при выполнении ЛР.

Важные детали условия:

- Ключи состоят из английских букв, длина до 256 символов, регистр не различается.
- Значение — целое число от `0` до `18446744073709551615`, то есть `2^64 - 1`.
- Повторное добавление ключа возвращает `Exist` и сохраняет прежнее значение.
- Успешный `Load` полностью заменяет рабочий словарь.
- Пустой файл и отсутствие файла при `Load` означают успех и пустой словарь.
- Ошибка чтения или повреждённый непустой файл означают `ERROR: ...`; рабочий словарь сохраняется.
- Для задания G нужны реальные исследования времени и памяти, дневник и сравнение версий. Условие разрешает аналоги gprof и dmalloc.

Обозначение `4` в названии варианта не задаёт минимальную степень дерева. В присланном условии конкретная степень B-дерева не указана.
