## Сборка

Windows, из папки report:

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
~~~

Скрипт использует Tectonic, иначе pdfLaTeX. Linux/WSL с TeX Live и русским языком: `make pdf`; альтернатива: `make tectonic`. Результат: `output/pdf/report-template.pdf`. Временные файлы находятся в игнорируемой папке `build/`. При первом запуске Tectonic может загружать пакеты TeX.

Для Overleaf загрузить папку report, главный файл — report.tex, компилятор — pdfLaTeX. Unicode-ветка Tectonic/XeLaTeX использует Times New Roman при наличии, иначе CMU Serif.

## Перед сдачей

1. Заменить плановые записи журнала фактическими; уточнить даты перенесённых этапов.
2. Внести результаты только из выполненных запусков, приложить логи и коммиты.
3. Проверить все поля в квадратных скобках.
4. Убрать обозначение «шаблон» после заполнения, пересобрать PDF и проверить оформление.
5. Сохранить итоговый отчёт и исходники его сборки.

Условие разрешает замену gprof и dmalloc аналогами. В методике предложены gprof и Valgrind; окончательный набор и версии нужно указать по факту. Команды из подготовки не являются результатами запуска над словарём.
